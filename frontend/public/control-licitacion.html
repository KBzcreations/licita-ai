4. Cómo utilizarlo

Primero genera una matriz en el analizador gratuito de LICITA. Descárgala como CSV y pulsa «Importar matriz CSV». Después asigna responsables, revisa las evidencias y marca cada requisito.

También puedes crear tareas manualmente y exportar el seguimiento para compartirlo en Excel. El botón «Crear ejemplo» incorpora un expediente ficticio para explorar la herramienta.

Versión local individual. Todavía no tiene cuentas, colaboración en tiempo real, recordatorios automáticos ni cobros. Nunca presentes este seguimiento como una verificación jurídica automática.
